# ЛР-1. Вариант 11

Функция Альпина № 1

## Запуск

```bash
python -m pip install numpy pandas matplotlib notebook
jupyter notebook LR1_variant11_code.ipynb
```


Запускаются две конфигурации ГА и случайный поиск: по 20 запусков на метод, seed 11001–11020, бюджет 29 500 оценок на запуск. В проверенной среде полное выполнение заняло около двух минут; время зависит от компьютера.

Каталог `results` создаётся автоматически. Ноутбук перезаписывает в нём `runs.csv`, `summary.csv`, `convergence.csv` и три PNG-графика.
