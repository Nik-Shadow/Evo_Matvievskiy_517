## Запуск

Установить библиотеки и открыть ноутбук:

```bash
python -m pip install numpy pandas matplotlib notebook

```


## Эксперимент

Две конфигурации ГА различаются только масштабом мутации: `sigma = 0.15` и `sigma = 1.00`. Третий метод — случайный поиск. По 20 запусков каждого метода, `seed = 11001..11020`.

Размер популяции — 100, элит — 2, новых поколений — 300. Бюджет каждого запуска: `100 + 300 * 98 = 29 500` оценок функции. Ориентир точности: `f(x) <= 1e-4`; досрочная остановка не используется. Масштаб мутации задаётся в единицах координат, не как доля ширины интервала.

Внутри каждой серии seed различаются. Между методами они совпадают для парного сравнения: первые 100 точек одинаковы. Это не 60 независимых друг от друга выборок, а 20 независимых запусков на метод.

## Файлы и результаты

`results/runs.csv` — 60 итогов и координаты; `summary.csv` — статистика; `convergence.csv` — 18 060 значений траекторий; `parameters.json` — параметры. Три графика создаются ноутбуком. Блок-схема приложена отдельно и включена в отчёт.

При повторном запуске ноутбук перезаписывает результаты в подкаталоге `results` текущей папки. Время работы может отличаться; числа и траектории воспроизводятся в той же программной среде. Версии проверенного окружения записаны в `environment.json`.
