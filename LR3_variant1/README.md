# Лабораторная работа № 3 — трек A, вариант 1

Дисциплина: «Эволюционное программирование и генетические алгоритмы».
Параметры студента: N=11, Q=1 (группа 517), Y=26. Формула даёт V=1.
Задача: многокритериальный выбор портфеля из 30 проектов — эффект (максимум),
стоимость и риск (минимум).

## Как запустить

1. Установить Python 3.10+ и библиотеки:

```bash
   python -m pip install numpy matplotlib notebook
   ```

2. Выполнить `jupyter notebook LR3\_code.ipynb` и в меню выбрать
**Run All** (или открыть ноутбук в Google Colab / VS Code).

## Воспроизводимость

* Генерация проектов: seed `202611`.
* Независимые серии: seed `3101`–`3120` для каждого метода.
* В базовом методе пять весовых сценариев, внутренний seed: `seed \* 10 + index`.
* 50 особей, NSGA-II — 104 поколения, взвешенная сумма — пять запусков по 20 поколений.
* Общий бюджет одного внешнего запуска каждого метода: 5250 оценок.
* Границы: стоимость <=135; число проектов 3–8.

## Файлы результатов

* `projects.csv` — исходные проекты;
* `runs.csv` — значения 20 запусков каждого метода;
* `summary.csv` — описательная статистика;
* `convergence.csv` — динамика NSGA-II;
* `pareto\_nsga.csv` и `pareto\_weighted.csv` — объединённые недоминируемые решения;
* `examples.csv` — три характерных портфеля;
* `.png` — графики и блок-схема.
